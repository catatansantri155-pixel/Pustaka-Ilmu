# Berkontribusi ke Maktabah Al-'Ilmiyyah

Terima kasih atas minat Anda. Proyek ini adalah aplikasi perpustakaan fatwa Islam; kontribusi kode dan dokumentasi sangat diterima.

## Cara berkontribusi

1. Fork repo ini, buat branch dari `main` dengan nama yang jelas (mis. `fitur/pencarian-lanjutan` atau `perbaikan/header-rapi`).
2. Lakukan perubahan sekecil dan sejelas mungkin; satu pull request untuk satu tujuan.
3. Pastikan aplikasi tetap berjalan: web dapat dibangun (`npm run build`) dan pengujian lulus.
4. Buka pull request dengan penjelasan: apa yang berubah, mengapa, dan bagaimana Anda memverifikasinya.

## Aturan konten (penting)

- Jangan menambahkan materi ulama mana pun tanpa izin tertulis dari pemegang haknya yang dapat diverifikasi. Materi yang ada saat ini: Syaikh Bin Baz (dengan atribusi).
- Jangan mengubah gerbang publikasi: materi hanya terbit setelah peninjauan admin.
- Aplikasi tidak mengeluarkan fatwa baru; jangan menambahkan fitur yang memutuskan hukum.

## Melaporkan masalah

Gunakan GitHub Issues: jelaskan langkah reproduksi, hasil yang diharapkan, dan hasil sebenarnya. Untuk kerentanan keamanan, jangan buka issue publik — hubungi pengelola repo secara pribadi.
